# Gated implementation

## Context

The approved behavior is in `../specs/2026-11-10-gated-design.md`. Use HD26's
nih-plug/softbuffer editor lifecycle, shared dials/dropdowns/text entry, and the
existing bundler's automatic workspace cdylib discovery. The existing shared
Gate effect is a threshold gate and is not the rhythmic sequencer required here.

## Changes

- Add `gated` to the workspace with CLAP/VST3 exports and standalone main.
- `pattern.rs`: copyable fixed-size pattern/bank, serializable two-word bitsets
  for future 128-step storage, bounded v1 length, editing and random population.
- `dsp.rs`: precompute the last note-on/off for every step when pattern, swing,
  or Gate changes. Advance ADSR in elapsed seconds during continuous playback
  so tempo changes retain millisecond timing; reconstruct from musical position
  after seeks and pattern changes, with constant per-sample work. Fold active
  loop boundaries even when they fall inside a host callback.
  An odd final step is unswung; ties across the loop remain continuous.
- `lib.rs`: global host parameters, persistent `Arc<Mutex<PatternBank>>`, cached
  copy acquired with `try_lock()` once per block, mono/stereo layouts, transport
  reconstruction and atomic display telemetry. No allocation or blocking lock
  in process. A 2 ms linear slew bounds gain jumps, including bypass/stop.
- `editor.rs`: real native editor, shared controls, ring interaction, bounded
  document undo and clipboard, dirty-state notification through the host.
  Use an external-state generation to clear stale gestures/history even when a
  recalled bank is identical. Render the same panel offscreen for screenshots.
- Add Markdown/PDF manual, screenshot, and repository indexes.

## Validation

- Pattern tests: max length, hidden data, clearing adjacent ties, wrap ties,
  rotation, density endpoints, deterministic seeded randomization, serde.
- DSP tests: ADSR stages and early release, tied runs, loop wrap, completely
  tied pattern, silence, negative positions, swing/odd lengths, exact cycle
  duration, resolutions, seek equivalence, finite bounded output, transitions,
  and invariance to audio buffer sizes.
- Native editor: compile standalone; render at base and alternate sizes; inspect
  screenshot; exercise slots, toggles/ties, undo, randomization, and resizing.
- Run focused nextest, fmt, workspace clippy, and bundle the new plugin.

## Later extension

Keep storage capacity separate from the exposed step limit. A Euclidean
population algorithm can write into the same pattern mutation and undo path
without changing DSP or persistence.
